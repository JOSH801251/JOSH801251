### 1. Online Boutique — Kubernetes, CI/CD & GitOps
[**View repository →**](https://github.com/JOSH801251/online-boutique-eks)

- Built a GitHub Actions matrix workflow to build and publish container images for the microservices.
- Configured Kubernetes manifests and Kustomize overlays for a local Minikube environment.
- Configured Argo CD for GitOps synchronization and demonstrated self-healing against configuration drift.
- Added Terraform configuration for a future AWS EKS deployment target; **the project is currently validated locally, not running on EKS**.

**Tools:** Docker · GitHub Actions · Kubernetes · Kustomize · Argo CD · Terraform · AWS

### 2. Jenkins CI/CD Pipeline — Docker & Kubernetes
[**View repository →**](https://github.com/JOSH801251/End-to-End-CI-CD-Pipeline-with-Jenkins-Docker-Kubernetes)

- Created a Jenkins Declarative Pipeline to build an Nginx-based website image.
- Used Jenkins credentials to authenticate to Docker Hub and publish the image.
- Added Kubernetes Deployment and NodePort Service manifests for deployment to the configured cluster.
- Documented the local Minikube workflow and validation commands.

**Tools:** Jenkins · Docker · Docker Hub · Kubernetes · Minikube · GitHub

### 3. AWS Three-Tier Web Application Architecture
[**View repository →**](https://github.com/JOSH801251/AWS-3-Tier-Application-Architecture)

- Documented a VPC architecture with public, private application and private database subnets.
- Covered an Application Load Balancer, EC2 application tier, Auto Scaling and Amazon RDS for MySQL.
- Included IAM, Systems Manager, CloudWatch and SNS configuration walkthroughs with screenshots.
- This is a **console-based implementation guide**, not an automated Terraform deployment.

**Tools:** AWS VPC · EC2 · ALB · Auto Scaling · RDS · IAM · CloudWatch · SNS
